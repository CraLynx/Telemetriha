# Telemetriha
![Image alt](https://github.com/CraLynx/Telemetriha/blob/main/Telemetriha.png)
Telemetriha — это Bash-надстройка для автоматической установки и управления MTProto proxy с использованием Telemt.

#  Важно: Telemetriha НЕ является частью Telemt и не является официальным продуктом Telemt.
##  Возможности

* Автоматическая установка и настройка MTProto proxy на базе Telemt
* Запуск как systemd-сервис
* Управление клиентами:

  * создание
  * удаление
  * включение / отключение
* Возможность указать порт вручную или использовать значение по умолчанию
* Быстрый запуск на чистой системе

##  Установка

Запуск одной командой:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/CraLynx/telemetriha/main/telemetriha.sh)
```

или

```bash
bash <(wget -qO- https://raw.githubusercontent.com/CraLynx/telemetriha/main/telemetriha.sh)
```

##  Требования

* Ubuntu 24.04 LTS
* root или sudo доступ
* подключение к интернету

##  Установка

Во время установки:

* будет предложено указать порт (или использовать по умолчанию)
* автоматически установятся зависимости
* настроится и запустится systemd-сервис

## 📡 Результат

После завершения установки вы получите:

* запущенный MTProto proxy (на базе Telemt)
* IP-адрес сервера
* порт подключения
* данные для подключения клиента (secret)

## 🔧 Управление

После установки доступен скрипт управления (например `manage.sh`).

Поддерживаемые операции:

* добавление клиента
* удаление клиента
* включение / отключение клиента
* просмотр списка клиентов

##  Сервис

Управление через systemd:

```bash
sudo systemctl status telemetriha
sudo systemctl restart telemetriha
sudo systemctl stop telemetriha
```
## Удаление

Для удаления:

```bash
bash uninstall.sh
```

##  Безопасность

* Скрипт не содержит встроенных паролей или токенов
* Рекомендуется:

  * настроить firewall (например, ufw)
  * ограничить доступ по SSH
  * регулярно обновлять систему

##  Важно

Лицензия и использование Telemt

Этот проект использует Telemt, распространяемый под лицензией TELEMT Public License 3.

В рамках использования Telemt соблюдаются следующие условия:

Telemetriha не модифицирует исходный код Telemt (если не указано иное)
Telemt устанавливается и используется как отдельный компонент
сохраняются все уведомления об авторских правах и лицензии Telemt
Telemetriha не использует название или брендинг Telemt таким образом, который может вводить в заблуждение
Важно
Telemetriha является сторонним инструментом
не является официальным релизом Telemt
не связан с разработчиками Telemt

При распространении или модификации необходимо соблюдать условия лицензии Telemt, включая:

сохранение текста лицензии
указание изменений (если применимо)
недопущение введения пользователей в заблуждение относительно происхождения ПО
